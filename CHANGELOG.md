# Changelog

## 1.0.1 — 2026-09-30
- Now also runs on Minecraft Java 1.21.1, 1.21.4, 1.21.8 and 1.21.11, as a data pack zip and a Fabric/Quilt mod jar for each of them. Nothing changes on 26.2 and 26.3.

## 1.0.0 — 2026-09-23
- First release for Minecraft Java 26.2 and 26.3. Needs Veinminer 1.1.0 or newer.
- New pickaxe enchantment, Veinminer (max level I). Only pickaxes with it veinmine; others break one block.
- Obtainable like Efficiency: enchanting table (rare, like Fortune), librarian books, chest loot and fishing, and enchanted villager pickaxes. Anvils combine it as usual. It can't go on other tools.
- Veinminer's join hint and settings menu say that the enchantment is needed.
- A chat warning, with a download link, if Veinminer is missing or older than 1.1.0, or if the pack was added with `/reload` instead of a restart.
- `/function enchanted_veinminer:uninstall` removes the add-on's data.
