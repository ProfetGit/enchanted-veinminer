**Veinmining becomes an enchantment.**

An add-on for **[Veinminer](https://modrinth.com/datapack/vanilla-veinminer)** (1.1.0 or newer; install both) for **Minecraft Java 26.2 and 26.3**. It adds the **Veinminer** pickaxe enchantment. Only a pickaxe that has it breaks the whole vein; without it, you mine block by block as in vanilla. Early on you dig the hard way, later you earn the shortcut.

![How to use](https://raw.githubusercontent.com/ProfetGit/enchanted-veinminer/main/docs/desc/title-how-to-use.gif)

1. Get the **Veinminer** enchantment on a pickaxe.
2. Sneak.
3. Mine an ore.

![The enchantment](https://raw.githubusercontent.com/ProfetGit/enchanted-veinminer/main/docs/desc/title-the-enchantment.gif)

- A real vanilla enchantment for any pickaxe, max level I, shown by name in the tooltip.
- Found like Fortune: at the enchanting table, as a librarian's book, in chest loot and fishing, and on enchanted pickaxes from toolsmiths and wandering traders.
- Combines on the anvil with every other pickaxe enchantment, including Fortune and Silk Touch.
- Veinminer's own rules still apply on top: sneaking, tool tier, durability and which ores count.

Operators can try it with `/enchant @s enchanted_veinminer:veinminer`.

![Installation](https://raw.githubusercontent.com/ProfetGit/enchanted-veinminer/main/docs/desc/title-installation.gif)

You need **Veinminer 1.1.0+** and this add-on.

- **Data pack:** put both `.zip` files in your world's `datapacks` folder, then **reopen the world or restart the server**. `/reload` isn't enough, because the game only registers enchantments when a world loads.
- **Mod:** put the `-fabric.jar` (Fabric or Quilt, needs Fabric API) or the `-forge.jar` (Forge or NeoForge) in `mods`, with Veinminer as a mod or a data pack.
- **Plugin:** put the `-plugin.jar` in `plugins`, with Veinminer as a plugin or a data pack, and restart. On Spigot and Bukkit, restart once more.

Removing the add-on removes the enchantment from every item the next time the world loads.
